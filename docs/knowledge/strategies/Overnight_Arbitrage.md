# 策略名称：隔日套利信号 (Overnight_Arbitrage)

## 基本信息

| 属性 | 值 |
|------|-----|
| 策略类型 | 量价分析 |
| 适用周期 | 日线 |
| 信号类型 | 短线套利机会 |
| 评分权重 | 20分 (满分100) |
| 实现函数 | `strategy.py::check_arbitrage_signal()` |

## 策略原理

隔日套利信号基于"量缩价稳"的量价关系原理，用于捕捉短线套利机会。

核心逻辑：
- **成交量递减**：近3日成交量逐日下降，表明抛压减轻
- **量低于月均**：最新成交量低于近20日均量，确认缩量状态

当成交量持续萎缩、抛压减轻时，股价往往进入"蓄势"状态，短期内可能出现反弹或突破。这种"量缩价稳"的形态是经典的短线套利信号。

套利策略的核心假设：缩量=抛压减轻=蓄势待发。但也需要警惕"缩量下跌"的风险，即缩量但股价持续下跌，可能是主力出货或市场无人接盘。

## 判断条件

**触发条件（必须全部满足）**：
1. 近3日成交量逐日递减（vol[-3] > vol[-2] > vol[-1]）
2. 最新成交量 < 近20日成交量均值

**判定逻辑**：
```python
# 量递减判定
vol_decreasing = recent_vol[0] > recent_vol[1] > recent_vol[2]

# 量低于月均判定
avg_vol = df.tail(21).head(20)["volume"].mean()
latest_vol = df.iloc[-1]["volume"]
vol_below_avg = latest_vol < avg_vol

# 综合条件
is_arbitrage = vol_decreasing and vol_below_avg
```

## 参数说明

| 参数名 | 默认值 | 说明 |
|--------|--------|------|
| lookback_days | 3 | 量递减检查天数 |
| monthly_avg_window | 20 | 月均量计算窗口 |

## 使用场景

### 最佳适用场景
- **短线套利**：捕捉缩量蓄势后的短线反弹机会
- **震荡市低吸**：震荡回调缩量时，可低吸等待反弹
- **突破前蓄势**：缩量整理后放量突破的拐点

### 不适用场景
- **暴跌缩量**：下跌缩量可能是无人接盘，而非蓄势
- **高位缩量**：高位缩量横盘可能是主力出货
- **流动性枯竭**：极度缩量可能失去交易价值

## 风险提示

1. **缩量下跌风险**：缩量不等于蓄势，也可能是下跌无承接
2. **流动性风险**：过度缩量的股票可能难以进出
3. **假蓄势风险**：缩量后可能继续下跌而非反弹

**应对策略**：
- 结合股价走势判断，缩量横盘优于缩量下跌
- 观察是否有支撑位（如BOLL中轨、均线支撑）
- 快进快出，套利性质不适合长期持有

## 与其他策略的配合

- **配合揉搓线**：缩量 + 揉搓线洗盘 = 蓄势充分
- **配合BOLL中轨**：缩量 + 价格在BOLL中轨附近 = 支撑确认
- **配合均线多头**：缩量蓄势在均线多头背景下更可靠

## 实战案例

### 案例1：平安银行 (000001) - 2024年4月

- **背景**：股价在支撑位横盘整理
- **信号**：连续3日缩量，成交量低于20日均量的60%
- **结果**：后续一周放量上涨约8%
