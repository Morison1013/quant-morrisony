# 策略名称：红色揉搓线洗盘 (RubbingLine)

## 基本信息

| 属性 | 值 |
|------|-----|
| 策略类型 | K线形态识别 |
| 适用周期 | 日线 |
| 信号类型 | 洗盘结束买入信号 |
| 评分权重 | 25分 (满分100) |
| 实现函数 | `strategy.py::check_rubbing_strategy()` |

## 策略原理

揉搓线是一种经典的K线洗盘形态，由两根特殊K线组成：
- **第一根K线**：长上影线（试盘上攻遇阻）
- **第二根K线**：长下影线（探底回升）

这种组合形态反映了主力"试上探下"的洗盘行为：先向上试探抛压，再向下试探承接，完成洗盘后往往迎来拉升。

本策略在揉搓线形态基础上，增加了三个过滤条件：
1. **BOLL中轨附近**：价格在中轨附近（偏差≤3%），确认支撑
2. **近期新高**：近10日内有创20日新高，确认前期强势
3. **缩量**：当日量≤20日均量×85%，确认洗盘而非出货

## 判断条件

**触发条件（必须全部满足）**：
1. 收盘价在BOLL中轨附近（偏差 ≤ 3%）
2. 近10日内有创20日新高
3. 缩量（当日量 ≤ 20日均量 × 85%）
4. 揉搓线形态（近3日有长上影 + 长下影，整体非明显阴线）

**揉搓线形态判定**：
- 长影线定义：影线 ≥ 实体 × 1.2 且 ≥ 全天范围 25%
- 需至少1根有长上影，1根有长下影
- 整体非明显阴线（收盘≥开盘或小实体十字星）

**判定逻辑**：
```python
# BOLL中轨附近
near_mid = abs(close - boll_mid) / boll_mid <= 0.03

# 近期新高
had_new_high = check_recent_new_high(df, window=20, check_days=10)

# 缩量
is_shrink = latest_vol <= avg_vol * 0.85

# 揉搓线形态
rubbing = check_red_rubbing_line(df)

# 综合条件
buy_signal = near_mid and had_new_high and is_shrink and rubbing["is_rubbing_line"]
```

## 参数说明

| 参数名 | 默认值 | 说明 |
|--------|--------|------|
| boll_period | 20 | BOLL中轨周期 |
| boll_std_dev | 2 | BOLL标准差倍数 |
| boll_mid_threshold | 0.03 | BOLL中轨偏差阈值 |
| high_window | 20 | 新高判定窗口 |
| high_check_window | 10 | 新高检查天数 |
| volume_threshold | 0.85 | 缩量阈值 |
| shadow_to_body_ratio | 1.2 | 影线/实体比例阈值 |
| shadow_to_range_ratio | 0.25 | 影线/全天范围比例阈值 |

## 使用场景

### 最佳适用场景
- **洗盘结束点**：主力洗盘完成，即将拉升
- **强势股回调**：前期强势股回调到支撑位
- **中短线布局**：洗盘后的拉升往往较快

### 不适用场景
- **下跌趋势**：下跌途中的揉搓线可能是反弹失败
- **高位揉搓线**：高位可能是诱多而非洗盘
- **放量揉搓线**：放量揉搓线可能是出货而非洗盘

## 风险提示

1. **假洗盘风险**：揉搓线后可能继续下跌而非拉升
2. **高位诱多风险**：高位揉搓线可能是主力诱多出货
3. **形态失效风险**：市场环境变化时形态可能失效

**应对策略**：
- 确认前期有强势表现（新高条件）
- 确认缩量而非放量（洗盘vs出货）
- 设置止损位，跌破BOLL中轨时离场

## 与其他策略的配合

- **配合均线多头**：均线多头背景下的揉搓线更可靠
- **配合MACD金叉**：MACD金叉确认趋势向上
- **配合缩量套利**：双重缩量确认=洗盘充分

## 实战案例

### 案例1：比亚迪 (002594) - 2024年2月

- **背景**：新能源龙头，前期强势后回调
- **信号**：
  - K-1长上影阳线（试盘上攻）
  - K-2长下影阳线（探底回升）
  - 价格在BOLL中轨附近
  - 缩量至20日均量的70%
- **结果**：后续两周上涨约12%

## 技术要点

**揉搓线的本质**：
- 试盘：主力试探上方抛压和下方承接
- 洗盘：震荡中清洗浮筹
- 蓄势：为后续拉升做准备

**红色揉搓线要求**：
- 整体非明显阴线（阳线或十字星）
- 避免下跌途中的"黑色揉搓线"
