# 策略名称：均线多头排列 (MA_Bullish)

## 基本信息

| 属性 | 值 |
|------|-----|
| 策略类型 | 技术指标 |
| 适用周期 | 日线 |
| 信号类型 | 趋势确认信号 |
| 评分权重 | 30分 (满分100) |
| 实现函数 | `strategy.py::check_ma_bullish_alignment()` |

## 策略原理

均线多头排列是一种经典的趋势确认策略，通过观察多条移动平均线的相对位置来判断股票的趋势强度。当短期均线依次位于长期均线之上时，表明市场多头力量强劲，股价处于上升趋势中。

本策略使用 6 条均线（5日、10日、20日、30日、55日、60日）进行综合判断，要求所有均线从短到长依次排列，即 MA5 > MA10 > MA20 > MA30 > MA55 > MA60。这种严格的排列条件能够有效过滤假突破，识别出真正的强势趋势。

均线系统的优势在于平滑价格波动、过滤噪音，但缺点是滞后性较强，适合作为趋势确认的辅助指标而非单独的交易信号。

## 判断条件

**触发条件（必须全部满足）**：
1. 计算 6 条移动平均线：MA5、MA10、MA20、MA30、MA55、MA60
2. 最新交易日的各均线值均有效（非 NaN）
3. 均线依次排列：MA5 > MA10 > MA20 > MA30 > MA55 > MA60

**判定公式**：
```python
for i in range(len(MA_PERIODS) - 1):
    short = f"ma{MA_PERIODS[i]}"
    long_ = f"ma{MA_PERIODS[i + 1]}"
    if last[short] <= last[long_]:
        return False  # 不满足多头排列
return True
```

## 参数说明

| 参数名 | 默认值 | 说明 |
|--------|--------|------|
| MA_PERIODS | [5, 10, 20, 30, 55, 60] | 均线周期列表 |
| min_periods | 各周期值 | 计算均线所需的最小数据点数 |

## 使用场景

### 最佳适用场景
- **趋势确认**：当股价已经有一定涨幅，需要确认趋势是否健康延续
- **中长线布局**：均线多头排列是中长线投资者的重要参考指标
- **强势股筛选**：全市场扫描时用于筛选处于强势趋势的股票

### 不适用场景
- **震荡市**：横盘震荡时均线频繁交叉，信号不稳定
- **底部反转**：底部区域均线尚未形成多头排列，会错过早期机会
- **短线交易**：均线滞后性强，不适合短线快进快出

## 风险提示

1. **滞后性风险**：均线是滞后指标，信号出现时股价可能已有较大涨幅
2. **假突破风险**：短期均线刚形成多头排列时，可能只是反弹而非反转
3. **高位钝化风险**：连续大涨后均线粘合，一旦方向选择向下会造成大幅亏损

**应对策略**：
- 结合 MACD 等动量指标确认趋势强度
- 观察成交量是否配合放大
- 设置止损位，跌破关键均线时及时离场

## 与其他策略的配合

- **配合 MACD 金叉**：均线多头 + MACD 金叉 = 强势确认
- **配合成交量**：均线多头 + 量价齐升 = 健康趋势
- **配合揉搓线**：均线多头背景下的揉搓线洗盘信号更可靠

## 实战案例

### 案例1：贵州茅台 (600519) - 2024年3月

- **背景**：股价经历调整后重新企稳，市场情绪回暖
- **信号**：MA5/10/20/30/55/60 形成完美多头排列
- **结果**：后续两个月股价上涨约15%，趋势健康延续
