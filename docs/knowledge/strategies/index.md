## 综合评分体系

系统对每只股票进行综合打分（满分100分）：

```
总分 = MA得分(30) + MACD得分(25) + 套利得分(20) + 揉搓线得分(25)
```

**评分标准**：
- 80分以上：强势信号，多策略共振
- 60-80分：中等信号，部分策略触发
- 40-60分：弱信号，需结合其他分析
- 40分以下：无明显信号

## 策略组合使用建议

### 强势启动组合
- 均线多头 + MACD金叉 = 趋势启动确认
- 适合：中长线布局，持股周期长

### 洗盘抄底组合
- 揉搓线 + 缩量套利 = 洗盘结束点
- 适合：短线抄底，快进快出

### 全面共振组合
- 4策略全部触发 = 最强信号
- 适合：重仓参与，设置止损保护
