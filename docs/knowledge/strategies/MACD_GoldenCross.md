# 策略名称：MACD 多周期金叉 (MACD_GoldenCross)

## 基本信息

| 属性 | 值 |
|------|-----|
| 策略类型 | 技术指标 |
| 适用周期 | 日线 + 周线 + 月线联动 |
| 信号类型 | 趋势启动信号 |
| 评分权重 | 25分 (满分100) |
| 实现函数 | `strategy.py::check_macd_golden_cross()` |

## 策略原理

MACD（移动平均收敛发散指标）是经典的动量指标，通过快慢两条指数移动平均线的差值（DIF）和其移动平均（DEA）来判断趋势方向和强度。

本策略采用**多周期联动**的方式，核心逻辑是：
- **月线 MACD 金叉**：代表中长期趋势向上
- **周线 MACD 未死叉**：中期趋势保持健康
- **日线 MACD 未死叉**：短期动能未衰竭

这种"月金叉、周/日不死叉"的组合条件，能够筛选出处于强势上升通道的股票，同时过滤掉短期动量衰竭的风险信号。

MACD 的优势在于能够提前反映趋势变化，金叉往往出现在股价起涨点附近，相比均线具有更好的前瞻性。

## 判断条件

**触发条件（必须全部满足）**：
1. 月线 MACD 处于金叉状态（DIF > DEA）
2. 周线 MACD 未死叉（DIF >= DEA）
3. 日线 MACD 未死叉（DIF >= DEA）

**参数定义**：
- 快线周期：12
- 慢线周期：26
- 信号线周期：9
- MACD柱计算：2 × (DIF - DEA)（同花顺风格）

**判定逻辑**：
```python
# 月线金叉判定
monthly_golden = monthly_dif > monthly_dea

# 周线/日线未死叉判定
weekly_death = weekly_dif < weekly_dea
daily_death = daily_dif < daily_dea

# 综合条件
is_golden = monthly_golden and not weekly_death and not daily_death
```

## 参数说明

| 参数名 | 默认值 | 说明 |
|--------|--------|------|
| fast | 12 | 快线EMA周期 |
| slow | 26 | 慢线EMA周期 |
| signal | 9 | DEA信号线周期 |

## 使用场景

### 最佳适用场景
- **趋势启动点**：月线金叉往往对应中长期趋势的启动
- **中长线布局**：多周期确认后，持股周期可拉长
- **强势股二次确认**：配合均线多头使用，双重确认趋势

### 不适用场景
- **震荡市**：MACD频繁金叉死叉，信号混乱
- **高位钝化**：连续大涨后MACD高位粘合，金叉信号失效
- **暴跌反转**：底部V型反转时MACD反应滞后

## 风险提示

1. **假金叉风险**：MACD金叉后可能很快死叉，需要观察后续走势确认
2. **高位风险**：月线金叉出现在股价高位时，可能是诱多信号
3. **周期错位风险**：月线金叉但日线已死叉，短期可能面临调整

**应对策略**：
- 金叉后观察3-5天确认信号有效性
- 结合成交量判断资金是否跟进
- 设置止损位，死叉时及时离场

## 与其他策略的配合

- **配合均线多头**：月MACD金叉 + 均线多头 = 强势启动确认
- **配合成交量**：MACD金叉 + 量增 = 资金认可度高
- **配合揉搓线洗盘**：MACD金叉背景下的洗盘形态可积极参与

## 实战案例

### 案例1：宁德时代 (300750) - 2024年1月

- **背景**：新能源板块复苏，股价从底部回升
- **信号**：月线MACD金叉，周线/日线保持金叉状态
- **结果**：后续三个月股价上涨约30%

## 技术说明

**周线/月线MACD计算方式**：
- 从日线数据重采样到周线/月线
- 周线：按周五收盘汇总
- 月线：按月末收盘汇总
- 需至少26根K线才能计算有效MACD
