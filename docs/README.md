# 文档

```
docs/
├── requirements/   # 需求文档
├── specs/          # 技术规格
└── milestones/     # 里程碑记录
```

### 命名规范

| 目录 | 文件名格式 | 示例 |
|------|-----------|------|
| requirements | `REQ-XXX-简要描述.md` | `REQ-003-SSE实时推送.md` |
| specs | `SPEC-XXX-简要描述.md` | `SPEC-005-自选股数据模型.md` |
| milestones | `MILESTONE-XXX-简要描述.md` | `MILESTONE-003-实时推送.md` |
